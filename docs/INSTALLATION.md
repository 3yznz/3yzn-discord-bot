# Installation — 3YZN Discord Bot

1. Install Python 3.11+.
2. Create and activate a virtual environment.
3. Install `requirements.txt`.
4. Copy `.env.example` to `.env`, set the bot token and development guild ID, then save.
5. Configure privileged intents in the Discord Developer Portal.
6. Run `python bot.py`.

Never commit `.env` or share your bot token.
